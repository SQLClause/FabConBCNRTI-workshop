# FabConBCNRTI-workshop
Repository for the labs for Johan and Brian's workshop Building Intelligent, Event-Driven Architectures with Fabric Real-Time Intelligence 

## Workshop components

- [`FabricIQ/`](FabricIQ/) - Fabric IQ workshop materials and labs.
- [`RTIBCN/`](RTIBCN/) - Azure Functions poller that streams live TMB bus and metro arrival data to Azure Event Hubs.
