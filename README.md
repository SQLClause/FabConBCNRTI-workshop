# FabConBCNRTI-workshop
Repository for the labs for Johan and Brian's workshop Building Intelligent, Event-Driven Architectures with Fabric Real-Time Intelligence 

## Workshop components

The day runs in two halves, numbered as one continuous sequence:

1. [`RTI/`](RTI/) - Real-Time Intelligence half (first): Modules 00–07.
2. [`FabricIQ/`](FabricIQ/) - Fabric IQ half (second): Modules 08–14.

Standalone short version:

- [`RTI-Express/`](RTI-Express/) - Real-Time Intelligence only, five labs in under 100 minutes, on Eventstream's built-in Bicycles sample (no Azure Function or Event Hubs needed).

Supporting code:

- [`RTIBCN/`](RTIBCN/) - Azure Functions poller that streams live TMB bus and metro arrival data to Azure Event Hubs.
